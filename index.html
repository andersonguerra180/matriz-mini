Matriz Mini

Enviar conversas do WhatsApp para o computador

CONVERSA
COMPUTADOR
Nenhum computador pareado

No computador, abra o Matriz Mini → IMPORTAR WHATSAPP e escaneie o QR code com a câmera do celular.

Se o Chrome perguntar sobre dispositivos na rede local, toque em Permitir.

INSTALAR (UMA VEZ SÓ)

Se o botão não aparecer: menu ⋮ do Chrome → Instalar app (ou Adicionar à tela inicial → Instalar).

ENVIAR UMA CONVERSA
  1. No WhatsApp, abra uma conversa → ⋮ → Mais → Exportar conversa.
  2. Na lista de compartilhamento, toque em Matriz Mini.
  3. A conversa vai direto para o computador pareado.
